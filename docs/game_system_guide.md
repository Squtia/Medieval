# 🛡️ 中世紀傭兵團經營 RPG 全系統指南 (Game System Guide)

本文件概述本專案的核心玩法架構、傭兵養成、戰鬥策略、封建內政與開發者工坊生態。

---

## 🗺️ 1. 世界地圖與 UI 架構系統
遊戲採用了**「三層式沉浸導覽架構」**：
- **世界地圖 (World Map)**：透過 Phaser 3 繪製 Isometric 2.5D 大地圖，包含各大勢力國家、軍事要塞與野外險地。支援滑鼠拖曳、縮放、視野迷霧與自然分岔道路網絡。點擊節點展開**「圓形選單 (Radial Menu)」**進行探索、討伐、偵查與跑商。
- **領地與國家街道 (Street View)**：展示城鎮街道風貌、NPC 訪客通道（支援直立肖像與多段對話）、右側共用領地面板與底部指令樞紐 (Command Crest Hub)。
- **獨立設施內部 (Facility Views)**：全螢幕進入書房、謁見廳、酒館、武器/防具商店與鐵匠鋪。

---

## 🏛️ 2. 領地內政與封建爵位系統
- **手動天數推進與每日/月底結算**：時間由玩家手動點擊「結束本日」推進，觸發資源生產、災難倒數與商業結算。
- **即時繁榮度模型 (Prosperity Index)**：領地規模（荒野 ➔ 營地 ➔ 村莊 ➔ 城鎮 ➔ 首都）嚴格由「總人口 + 建築等級分 + 完工道路數 + 附庸節點 - 危險壓制」動態計算。
- **封建爵位晉升 (Noble Titles)**：平民 ➔ 騎士 ➔ 男爵 ➔ 子爵 ➔ 伯爵 ➔ 侯爵 ➔ 公爵 ➔ 國王。晉升解鎖官職槽位 (Office Slots)、商隊上限、名冊上限與每日稅收。
- **生產設施與勞動力**：升級農田、伐木場、採石場與獵場提升倍率槓桿，少量人口即可供應全城軍民口糧與素材。

## 🦸 3. 傭兵養成、八維屬性與滿等轉職
- **八維屬性模型**：力量 (STR)、敏捷 (AGI)、體質 (CON)、智慧 (INT)、精神 (SPR)、幸運 (LUK)、魅力 (CHARM) 與統帥 (CMD)。
- **物魔雙軌與大一統戰力**：物理攻擊 (STR*2)、魔法攻擊 (INT*2)、物防 (CON+STR/2)、魔防 (CON+SPR/2)，傭兵與怪物 100% 共用大一統戰力計分公式。
- **滿等 Lv.10 進階與變異轉職**：
  - 6 大基礎職業（戰士、法師、弓箭手、騎士、盜賊、祈禱者）。
  - Lv.10 滿等時依**裝備武器**晉升為 12 大一般或變異進階職業（如狂戰士、魔劍士、大魔導士、死靈法師、神射手、精靈使、聖騎士、符文騎士、暗殺者、詭術師、大主教、異端拷問官），解鎖專屬終極技能與被動特質。
- **唯一傳奇英雄 (UR/SSR)**：收錄專屬名冊（如雷恩、露娜、誓約守衛），支援專屬立繪與雙實體綁定。

## ⚔️ 4. 裝備體系、T1~T5 階級與職業綁定
- **三大裝備槽位**：主手武器 (Weapon)、身體防具 (Armor)、飾品 (Accessory)。
- **嚴格職業與武器綁定 (SSOT)**：
  - 戰士：巨劍、雙劍、重鎧。
  - 法師：法杖、戰鐮、布甲。
  - 弓箭手：戰弓、魔法弓、皮甲。
  - 騎士：劍盾、符文盾、重鎧。
  - 盜賊：雙匕首、魔法戒指、皮甲。
  - 祈禱者：聖典、戰鎚、布甲。
- **T1~T5 Scaling 與詞綴**：武器保底核心主屬性，隨機附加 0~2 條副屬性與前綴。
- **鍛造與強化 (+0 ~ +10)**：鐵匠鋪支援強化、重鑄、附魔（火/冰/雷/暗/聖五大元素）與裝備改造所前綴洗鍊。

---

## 🎮 5. 戰術戰鬥與動態副將接替
- **GAMBIT 戰術條件鏈**：自訂傭兵 AI 施放優先級（目標血量、狀態觸發、技能選擇）。
- **互動式回合戰鬥 (Interactive Combat)**：支援手動技能施放、領主軍師戰術指揮與攻城撞門機制。
- **雙實體與動態副將接替 (Dynamic Vice-Commander Engine)**：敵方名將英雄被玩家俘虜、招募或擊殺時，敵軍自動動態生成代理副將接替出戰，保證戰役與據點進程無縫推進。
- **元素相剋體系**：冰 ➔ 火 ➔ 雷 ➔ 冰 順剋 1.25x / 逆剋 0.75x；光暗互剋 1.5x。

---

## 📜 6. 故事化懸賞、NPC 訪客與碎片化敘事
- **故事工坊全面連動**：支援多線分支劇情、日常委託懸賞（`repeatable: true`）與英雄條件/入隊獎勵。
- **街道 NPC 訪客通道**：支援 1:1.853 直立肖像、多段沉浸式對話與交涉結算。
- **隨機探險事件**：派遣部隊探索據點時動態觸發文字抉擇與歷史碎片解讀。

---

## 🛠️ 7. 五大獨立開發工坊生態 (Developer Studios)
專案提供 5 套獨立視覺化開發工坊（僅在 Vite DEV 模式運作）：
1. **📖 故事工坊 (`tools/story-studio.html`)**：多線分支、條件/獎勵排程與日常懸賞任務。
2. **⚔️ 戰鬥平衡工坊 (`tools/combat-studio.html`)**：戰鬥模擬沙盒 (1場/100場)、64+ 魔物母庫、英雄名冊與討伐據點配置。
3. **⚡ 全自訂積木技能工坊 (`tools/skill-workshop.html`)**：視覺化傷害/治療/狀態/護盾積木組合與效果編譯器。
4. **🔨 裝備素材工坊 (`tools/equipment-studio.html`)**：武器、防具、飾品、素材與配方庫視覺化管理。
5. **🎨 全圖集圖標工坊 (`tools/icon-studio.html`)**：Sprite 切片索引與全域 `?flip` 水平鏡像支援。
