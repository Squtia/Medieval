# 故事工坊操作指南

## 開啟方式

在 Vite 開發環境的遊戲畫面直接盲打 `story`，或開啟 `/Medieval/tools/story-studio.html`。正式遊戲不包含工坊。

## 編排觀念

- 一個「故事」包含多個「節點」。
- 節點的畫面順序不代表觸發順序；條件、線索與排程才決定順序。
- 「完成後結果」一定會執行；「玩家選項結果」只執行玩家選中的那一組。
- 所有條件與結果都可用「＋」新增多筆，右側的「刪除」只刪除該筆。

## 條件類型

- 最早遊戲日、最低酒館等級、最低聲望。
- 需要線索、必須尚無線索。
- 取得指定線索後等待若干天。
- 需要已發現的地圖節點。

同一節點可放多筆相同類型，例如同時要求 `burned_ledger` 與 `guard_testimony`。

## 結果與獎勵類型

- 新增線索。
- 金幣、聲望、經驗池。
- 素材、貿易品、指定裝備。
- 延遲排程其他故事節點。
- 解鎖預設地圖據點。
- 創造故事討伐據點。

素材、貿易品與裝備使用專案資料庫 ID；若 ID 不存在，結構檢查會阻止寫入專案。

## 創造故事討伐據點

新增一筆「創造故事討伐據點」結果後可設定：

- 據點代號、名稱與描述。
- `NEAR_PLAYER`：在玩家領地附近生成。
- `NEAR_NODE`：在指定既有地圖節點附近生成。
- `FIXED`：使用固定 X／Y 百分比座標。
- 距離、地形、難度 1～10、敵軍特性與主題怪物 ID。
- 是否需要偵查、勝利後是否移除。
- 途中事件節點，可用逗號依序填入多個節點代號。
- 勝利後節點與失敗後節點。

生成 ID 會固定為 `story_<故事代號>_<據點代號>`；同一效果重複執行不會生成第二座。據點會隨地圖資料存檔。測試模式重置故事時會移除該故事生成的測試據點。

## 「失蹤的商隊」完整操作示範

1. 選擇節點「尋找失蹤的丈夫」。完成結果中可同時看到 `caravan_rescued`、`burned_ledger` 與三天後排程 `warehouse_cargo`。
2. 選擇「倉庫裡的陌生貨物」，展開玩家選項。
3. 第一個選項「封存貨物並追查來源」會給予 `smuggler_clue`、10 聲望，並創造「走私者的廢棄關卡」。
4. 討伐設定指定 `bandit`、遺跡地形、難度 2、需要偵查；途中節點為 `checkpoint_approach`。
5. 「泥濘中的車轍」是討伐途中事件。追查車轍會取得 `checkpoint_side_gate` 與兩個鐵錠；保持隊形則取得 `checkpoint_cautious`。
6. 勝利會觸發「關卡地下的帳冊」，給予香料、鐵錠、鐵大劍與經驗池；失敗則觸發「走私者的反擊」。

## 不寫入專案的測試方式

1. 在工坊選擇要測試的節點，按「在遊戲中測試」。
2. 按「強制顯示此節點」測試文本與選項。
3. 在「倉庫裡的陌生貨物」選擇追查來源後，測試面板會顯示已生成的故事討伐據點。
4. 使用「模擬下一個討伐途中事件」、「模擬故事討伐勝利」或「模擬故事討伐失敗」檢查分流。
5. 選擇勝利／失敗節點並強制顯示，可確認結果獎勵。
6. 按「重置此故事測試進度」重新測試；不會寫入正式存檔。

確認完成後回到工坊按「寫入專案」，才會更新 `src/data/custom_stories.json` 並建立歷史快照。
