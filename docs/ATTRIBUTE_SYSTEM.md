# 🛡️ 屬性系統與運算公式 (Attribute System & Formulas)

本文件整理了遊戲中角色與傭兵的「八維屬性模型」，以及基於這些屬性衍生出的所有戰鬥數值、內政跑商與回復抵抗等運算公式。

---

## 🌟 1. 八維屬性總覽 (The 8 Attributes)

每一位傭兵與角色皆擁有基礎的六維戰鬥屬性與兩種特殊的內政/統御屬性：

| 屬性 | 英文縮寫 | 核心功能定位 |
| :--- | :--- | :--- |
| **力量** | STR | 決定物理攻擊力，並影響防禦與負重能力。 |
| **敏捷** | AGI | 決定迴避率與命中率，並影響戰鬥中的出手順序。 |
| **體質** | CON | 決定生命上限 (Max HP)、物理防禦力與每回合 HP 恢復量。 |
| **智慧** | INT | 決定魔法攻擊力、魔法防禦力、補血量，並影響跑商議價與載重。 |
| **精神** | SPR | 決定魔力上限 (Max MP)、每回合 MP 恢復量，以及對抗負面狀態的抗性。 |
| **幸運** | LUK | 影響爆擊率(特定技能)、額外命中與少許迴避，以及尋寶機率(未實裝)。 |
| **魅力** | CHARM | 非戰鬥屬性。影響跑商的議價能力與載重量，並在傭兵退休時給予領地永久稅收加成。 |
| **統帥** | CMD | 非戰鬥屬性。保留給未來「軍團系統」與「官職系統」使用，高統帥者適合擔任隊長或方旗騎士。 |

## ⚔️ 2. 戰鬥派生數值公式 (Combat Stats Formulas)

角色的實際戰鬥數值 (HP, MP, ATK, DEF, HIT, EVADE) 是由八維屬性套用特定公式推導而來。
裝備所提供的固定數值加成會在最後疊加。

### 基礎公式 (物魔雙軌制)
*   **最大生命 (Max HP)** = `CON * 10`
*   **最大魔力 (Max MP)** = `SPR * 5`
*   **物理攻擊力 (PATK)** = `STR * 2` *(力量決定物理輸出)*
*   **魔法攻擊力 (MATK)** = `INT * 2` *(智慧決定魔法輸出)*
*   **物理防禦力 (PDEF)** = `CON + ⌊STR * 0.5⌋` *(體質為主要防禦來源，力量加強物理抵擋)*
*   **魔法防禦力 (MDEF)** = `CON + ⌊SPR * 0.5⌋` *(體質為主要防禦來源，精神加強魔防抗性)*
*   **命中值 (HIT)** = `AGI * 2 + LUK`
*   **迴避值 (EVADE)** = `AGI * 1 + LUK`
*   **爆擊率 (CRIT %)** = `5% + ⌊(HIT / 500) * 100⌋%` *(弓箭手與雙匕首享職業/武器額外加成)*
*   **爆擊傷害 (CRIT DMG %)** = `150%` *(神射手/戰弓特化為 200%)*

### 戰鬥力估算 (Power)
*   **綜合戰鬥力** = `STR + AGI + CON + INT + SPR + LUK` 
    *(不含裝備戰鬥屬性，僅反映角色肉體素質的簡單加總)*

## 🛡️ 3. 戰鬥恢復與狀態抵抗機制 (Regen & Resistance)

在戰鬥迴圈中，體質 (CON) 與 精神 (SPR) 扮演著極其重要的續航與防禦角色：

### 每回合自動恢復 (Per-Turn Regeneration)
當輪到該角色行動時，會自動觸發回復：
*   **HP 恢復量** = `MAX(1, ⌊CON * 0.2⌋)`
*   **MP 恢復量** = `MAX(1, ⌊SPR * 0.2⌋)`

### 狀態抵抗檢定 (Status Resistance)
當角色即將被附加負面狀態（如：中毒、流血、暈眩、破甲、感電）時，系統會進行抵抗檢定：
*   **抵抗機率** = `(CON + SPR) * 1%`
*   *範例：若體質 15、精神 20，則擁有 35% 的機率顯示「抵抗了負面狀態！」並免疫該次異常。*

## 💰 4. 跑商與內政運算 (Trade & Civic Stats)

非戰鬥屬性主要應用於大世界探索與市場交易：

### 跑商特長 (Trade Stats)
由「魅力」與「智慧」共同決定商隊的承載與議價能力：
*   **最大載重量 (Max Cargo)** = `(CHARM + INT) * 5`
*   **議價加成 (Negotiation Bonus)** = `MIN(20%, (CHARM + INT) / 100)`
    *(最高可獲得 20% 的買賣價格優惠)*

### 退休轉任 (Retirement)
*   當玩家將傭兵「永久退休轉任」時，會根據該傭兵的 **魅力 (CHARM)** 值，給予領地永久的稅收或繁榮度加成。

## ⚒️ 5. 裝備門檻與職業成長 (Equipment & Growth)

*   **裝備條件 (Requirements)**：裝備無職業限制，但會有嚴格的屬性門檻。例如巨劍需要 `STR >= 20`，法杖可能需要 `INT >= 15` 與 `SPR >= 10`，未達標則無法裝備。
*   **升級成長 (Level Up)**：傭兵滿等為 Lv.10。每次升級會根據其「職業成長係數 (Growth Rates)」微幅提升基礎屬性，並給予 **2 點自由屬性點**供玩家手動分配。
*   **性格補正 (Traits)**：傭兵的性格會給予最終六維屬性百分比的加成或懲罰（例如：魯莽可能給予 STR +10%、AGI -5% 的修正）。
