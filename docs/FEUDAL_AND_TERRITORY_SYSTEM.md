# 🏰 封建爵位、領地規模與內政建築系統手冊 (Feudal Titles, Territory & Civic System)

> **版本**：v1.0 (2026-08-15)  
> **適用範圍**：封建爵位晉升、領地五大擴張規模、即時繁榮度評分公式、四大基礎生產設施與城鎮五大建築。

## 🎯 一、核心設計理念 (Core Philosophy)

1. **拒絕虛胖人口，封建爵位與領地規模 100% 雙向咬合**：
   * 廢除「升公爵需要 5000 虛胖人口」的不合理數值，改以**「領地實質繁榮度（硬實力）+ 領主聲望（戰功）+ 晉升大典金幣」**三維一體受封爵位。
   * 領主爵位的受封直接對應領地的規模擴張（騎士 ➔ 營地、男爵 ➔ 村莊、伯爵 ➔ 城鎮、公爵 ➔ 首都）。

2. **繁榮度回歸「即時領地綜合評分 (Prosperity Index)」**：
   * 繁榮度不再是無上限單向累加的假性 EXP，而是領地當前綜合實力的**「單一真相來源（Single Source of Truth）」**。
   * 繁榮度隨人口增減、設施升級、道路完工、附庸征服即時響應；周邊出現高危動態魔物巢穴時則受動態壓制。

3. **生產設施倍率槓桿，少量農夫養活攻城軍團**：
   * 透過開墾升級農田、伐木場、採石場、獵場，提升產能倍率（1.0x ➔ 3.0x），讓少量人口即可供應全城軍民口糧與工匠素材，支撐大規模遠征。

### 2. 即時繁榮度公式 (`Territory.getRealtimeProsperity`)
$$\text{即時繁榮度} = \text{當前總人口} + \sum(\text{基礎設施固定分}) + \sum(\text{城鎮建築固定分}) + (\text{完工道路數} \times 25) + (\text{附庸據點數} \times 100) - \text{周邊危險扣分}$$

* **當前總人口**：每 1 名村民（不論指派或閒置）提供 **+1 繁榮分**。
* **基礎設施固定分**：四大生產設施升級提供穩定繁榮評分（Lv.1=0, Lv.2=10, Lv.3=25, Lv.4=45, Lv.5=70）。
* **城鎮建築固定分**：城鎮 5 大建築提供繁榮評分（Lv.1=10, Lv.2=25, Lv.3=45, Lv.4=70, Lv.5=100）。
* **完工道路加成**：領地每連通 1 條完整道路，提供 **+25 繁榮分**（商貿通達）。
* **附庸王國加成**：每征服並擁有一處附庸據點，提供 **+100 繁榮分**（封建宗主威權）。
* **動態危險壓制**：領地 15 格內若存在探索觸發的動態怪物巢穴，繁榮度扣減 **20 分**。

### 2. 官職體系 (Offices)
領主可在謁見廳將退役或在役的高階冒險者冊封為領地官員，獲得被動治國加成：
* **🛡️ 扈從 (Retainer)**：貼身護衛，降低領主遭遇刺殺與意外機率。
* **⚔️ 隊長 (Captain)**：統率衛兵，顯著提升治安值與據點防禦戰力。
* **🏰 城主 (Castellan)**：代理領地內政，提升全體生產設施產出效率與商業稅收。
* **🚩 方旗騎士 (Banneret)**：召集封建領主聯軍，提升商隊護衛戰力與遠征軍團士氣。
