# 開發測試密技指南 (Cheat Codes)

為了方便在開發階段快速驗證系統與機制，遊戲內建了一套隱藏的「密技系統 (`CheatController.ts`)」。

## 觸發方式
不需要開啟任何控制台，只要在遊戲主畫面（沒有聚焦在任何輸入框的情況下），直接使用鍵盤**連續盲打**對應的英文字母，即可觸發。

## 密技列表

### 1. 資源與屬性修改 (會跳出數值輸入框)
輸入以下指令後，系統會跳出提示框要求您輸入一個整數（正負數皆可），輸入完畢後會立即更新領地數值。

*   `gold`：修改**金幣**總量
*   `wood`：修改**木材**總量
*   `rock`：修改**石材**總量
*   `iron`：修改**鐵礦**總量
*   `allres`：一次性同時增加**所有物資** (金幣、木材、石材、鐵礦、生皮、棉麻)
*   `fame`：增加/減少**聲望** (`prestige`)
*   `army`：增加/減少**軍隊人數**（會等比例分配給步兵、騎兵與弓箭手，並觸發總人口更新事件）
*   `tavern`：直接設定**酒館等級** (輸入 0~5，會自動解鎖酒館建築)

### 2. 領地設施與轉職裝備測試 (無須輸入，立即生效)
輸入以下指令後，會直接執行系統級的測試操作，不會跳出對話框。

*   `buildmax`：**一鍵全建築與設施滿等**
    *   作用：將領地所有建築（酒館、武器店、防具店、鍛造屋、防衛設施）及四大生產設施（農田、伐木場、採石場、獵場）全部解鎖並升至 5 等滿級。
    *   用途：用於快速解除所有需要高階建築或高階酒館才能觸發的故事與系統門檻。
*   `lvlmax`：**一鍵全軍滿等**
    *   作用：將隊伍中所有傭兵的等級直接提升至 10 等，並發放屬性點數。
    *   用途：用於快速準備好觸發轉職的等級門檻。
*   `advanc`：**強制解鎖轉職開關**
    *   作用：將所有達 10 等的傭兵的 `isAdvanced` 狀態直接切為 true。
*   `advmat`：**發放所有轉職專屬素材**
    *   作用：將所有轉職試煉所需的素材 (如狂怒之鋒、秘法魔典等) 各給 10 個。
    *   用途：用於測試正統的 UI 點擊消耗轉職流程。
*   `testwpn`：**獲取全套滿等測試武器**
    *   作用：直接將四把屬性門檻較低的測試專用武器（滿等巨劍、雙劍、法杖、戰鐮）發放至領地倉庫中。
    *   用途：讓剛轉職的傭兵馬上擁有觸發變異/進階的裝備，不須費時打怪掉落。

### 3. 唯一傳奇英雄召喚 (無須輸入，立即加入隊伍)

*   `addur`：**召喚唯一 UR【赤焰戰神】雷恩·瓦倫泰**
    *   作用：直接生成滿等進階、裝備 T4 +7 隕鐵巨劍與皇家重鎧之 UR 狂戰士。
*   `addssr`：**召喚唯一 SSR【霜語大魔導】露娜·星輝**
    *   作用：直接生成滿等進階、裝備 T4 +5 賢者法杖與大法師法袍之 SSR 大魔導士。
*   `addoath`：**召喚唯一 UR【神聖誓約騎士】**
    *   作用：直接生成滿等進階、裝備 T4 +7 皇家聖騎士劍盾與誓約守衛專屬立繪之 UR 聖騎士。

### 4. 五大開發工坊與美術編輯器（無須輸入，立即開啟）

*   `studio`：在新分頁開啟全圖集圖標工坊 (`icon-studio.html` / `openIconStudio()`)。
*   `story`：在新分頁開啟故事工坊 (`story-studio.html` / `openStoryStudio()`)。
*   `combat` / `battle`：在新分頁開啟戰術遭遇與戰鬥平衡工坊 (`combat-studio.html` / `openCombatStudio()`)。
*   `equip` / `material` / `forge`：在新分頁開啟裝備、素材與配方工坊 (`equipment-studio.html` / `openEquipmentStudio()`)。
*   `skill`：在新分頁開啟全自訂積木技能工坊 (`skill-workshop.html` / `openSkillWorkshop()`)。
*   `layout` / `edit`：在遊戲畫面直接喚醒即時排版與美術佈局編輯器 (`LiveLayoutEditor.toggle()`)。
*   `theme`：開啟全域視覺主題工坊 (`UIThemeStudio.open()`)。

> [!WARNING]
> 這些指令僅存在於開發環境 (DEV) 或特別保留的後門，在正式發佈環境中 `CheatController.ts` 不會執行，避免破壞玩家體驗。
