# 平衡測試基準報告

> 更新日期：2026-08-17  
> 性質：P0 量測基準，不代表最終平衡目標

## 1. 驗證入口

- `npm run test:balance`：怪物基準、戰力結構與固定種子的 5v5 隊伍模擬。
- `npm run test:economy`：普通／困難各 360 天的固定策略經濟模擬。
- `npm run test:smoke`：新遊戲、誓約創角、序章、探索、道路、每日推進、存檔與讀檔。
- `npm run test:p0`：依序執行型別、單元測試與上述三類 P0 驗證。

所有平衡腳本均使用固定 seed，並將 `Math.random` 暫時導向專案的 seeded random source。腳本檢查失敗時必須回傳非零 exit code。

## 2. 戰鬥基準

固定 seed 的難度 1 據點產生 2 隻敵人、總戰力 68。對 HP 150 的測試傭兵，食屍鬼物理普攻造成 13、薩滿魔法普攻造成 25，均為非致死傷害。

### Lv.10 5v5 量測

| 隊伍 | 勝率 | 平均行動數 |
| --- | ---: | ---: |
| 物理單體 | 100% | 27.1 |
| 魔法群攻 | 97% | 31.5 |

防具 fixture 已改用正式 `combatEffects`，並在模擬前驗證 HP、PDEF、MDEF 加成確實生效。上述勝率只說明目前測試遭遇對三隊都偏容易，不應直接作為職業增減傷依據。

Lv.1 戰士在固定的難度 1、雙怪遭遇中戰敗；此結果會如實顯示，不再被「戰鬥事件有產生」誤報為平衡通過。

## 3. 經濟基準

模擬採「平衡型自動策略」：優先維持治安與糧食、分配剩餘人口採集木石、資源足夠時依序升級設施與建築、自動派遣／領取懸賞，酒館成立後保留安全金再招募。模擬不建免費道路，也不假設玩家能完美操作，因此是可重播的基準線，而非最佳攻略。

## 4. 解讀限制

- 固定策略不會重現真人玩家的探索、戰鬥、跑商與道路選擇。
- 目前 5v5 遭遇不適合作為最終 Boss 強度基準，因三種隊伍勝率皆過高。
- 經濟結果適合比較版本間回歸，不適合單獨證明遊戲已經平衡。
- 後續每次正式數值調整都應保留 seed 與策略版本，避免基準線無法重播。
