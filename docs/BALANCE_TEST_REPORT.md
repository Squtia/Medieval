# 全職業 5v5 團隊平衡測試報告 (v1.0)

## 測試環境與條件
- **測試目標**：檢驗「動態戰略大腦 (Smart Casting AI)」與「大招冷卻機制」實裝後，各職業在標準 5v5 推進戰中的表現。
- **我方隊伍 (Heroes)**：
  - 角色設定：全為 **Lv 10 (滿等進階狀態)**。
  - 角色素質：極品素質 (八維基礎屬性全為 50)。
  - 裝備設定：配置各職業專屬頂級裝備 (如神射手持戰弓、詭術師持魔法戒指等)。
  - 核心成員：【聖騎士 (坦)】 + 【大主教 (補)】 兩名固定成員。
- **敵方陣容 (Enemies)**：5 隻「深淵戰神」(HP 2000, 基礎攻擊/防禦 80/60) 的菁英怪群。
- **模擬次數**：每組陣容各進行 100 次獨立自動戰鬥。

  3. **暗殺者**：635 傷

### 🔮 陣容 B：極致魔法群攻隊

## 分析與結論

1. **狀態連動與斬殺連鎖的化學反應極強**：
   陣容 C 的推進速度遠超 A、B 兩隊，主因在於**「詭術師」的疊毒與引爆**快速壓低單體血線，隨後交由**「死靈法師」的【死神收割】**進行斬殺。一旦斬殺成功，【死神收割】會自動無消耗對下一個目標施放，引發連續收割效應。
2. **AI 施法邏輯正確運作**：
   在測試中，聖騎士能準確在血線危急時開啟護盾，大主教能精準施放「神聖之雨」淨化負面狀態並確保 MP 不被無效治癒浪費，確保了 100% 的勝率基石。
3. **後續平衡建議**：
   - 死靈法師的無限斬殺機制上限極高，未來若需降速，可考慮加上「每回合最多連鎖 X 次」或「收割後傷害遞減」的限制。
   - 物理隊 (陣容 A) 表現中規中矩，未來可考慮增強暗殺者的出血聯動效果以提升單體爆發力。
