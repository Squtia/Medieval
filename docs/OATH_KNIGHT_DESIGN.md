# 誓約騎士人物與專屬任務設計手冊 (Oath Knight Design & Questline)

---

## 1. 核心定位與敘事基調 (Core Philosophy)

### 1.1 拒絕中二與中式道德綁架
- **非動漫爽文**：不使用誇張的覺醒招式、狂暴龍血、邪魅冷笑或宣告式情緒。
- **非中式三國託孤**：老領主與誓約騎士不是「君臣死士、道德綁架」的關係，而是回歸西歐中世紀封建誓約的**克制、冷靜、信任與尊嚴**。
- **患難與共**：誓約騎士與玩家一同從滅門逃亡中走出，起步於泥濘與寒夜，手持一把被煙燻血漬覆蓋的舊鋼劍，共同在荒野開拓營地。

### 1.2 品階成長階梯
誓約騎士為全遊戲唯一貫穿始終的專屬夥伴，初始品階為 **N**，最高可突破至 **UR**：
- **N（開局初始）** ➔ **R（第一次突破）** ➔ **SR（第二次突破）** ➔ **SSR（第三次突破）** ➔ **UR（終極覺醒）**

## 2. 滅門之夜與寶劍託付 (The Fall of the Keep)

### 2.1 歷史情境
突襲發生在深夜，內應開門，城堡陷入火海。老領主在先前的近身廝殺中腹部重創，深知帶著傷員走密道絕無生還可能。

### 2.2 寶劍託付（克制與寫實）
老領主沒有長篇大論的哀求或命令，在狹窄地道的鐵柵前，他只是解下佩劍，交給身邊最信任的隨從：

> *「外面的吊橋斷了，地道鐵門只能從裡面卡死。」*  
> *「帶上孩子，拿著這把劍，往東邊的荒野走。不要回頭看。」*  

- **劍的象徵**：這把劍不是權力的施捨，也不是道德的枷鎖，而是老領主在生命最後時刻，將血脈與家名的象徵，交付給他唯一能托付背後的人。
- **騎士的沈默**：誓約騎士沒有激動發誓，只是接過冰冷的鐵鞘，背起年幼的領主遁入黑暗。

## 3. 傳家寶劍與美德符文體系 (The Ancestral Blade & Runes)

### 3.1 寶劍狀態演進
- **初始狀態（N 品階）**：
  - 名稱：**【破敗的傳家寶劍】** (`wpn_heirloom_sword`)。
  - 外觀：雙手鋼劍，劍刃有缺口，銘文被煙垢與血漬浸透遮蔽。
- **解封過程**：
  - 每次完成專屬突破任務，騎士在重大危機中踐行一項騎士美德，洗去劍身一層泥垢，點亮一枚古代刻痕符文。
- **終極形態（UR 品階）**：
  - 符文完全點亮，顯現正式家族真名（如《守誓之證》/《晨曦誓約》），成為傳奇家族神兵。

### 3.2 騎士八大美德庫 (The Eight Chivalric Virtues)
作為解鎖各階段符文的命題核心：
1. **謙卑 (Humility)**：不矜不伐，敬畏職責與生命。
2. **榮譽 (Honor)**：信守盟約與言諾，行事無愧。
3. **犧牲 (Sacrifice)**：危難之時以大局與同袍為先，不惜己身。
4. **英勇 (Valor)**：戰勝恐懼，在絕境中拔劍直面強敵。
5. **憐憫 (Compassion / Mercy)**：以武止戈，庇護弱者，不濫殺降卒。
6. **堅定 (Perseverance)**：在漫長的寒冬與流亡中不變節、不迷失。
7. **誠實 (Honesty)**：行事光明磊落，不假偽善，對領主直言進諫。
8. **公正 (Justice)**：持劍如天平，按法度裁決，不偏袒私利。

## 4. 四階段專屬任務線架構 (Quest Progression)

### 階段一：N ➔ R【寒冬殘鐵】（堅定 / 忠誠）
- **情境**：營地初建的第一個冬天，物資匱乏，流寇與逃兵試圖洗劫糧倉。
- **考驗**：誓約騎士在沒有援軍的黑夜中持生鏽之劍守在門口，擊退夜襲。
- **結果**：洗去第一層血污，護手處浮現第一道古樸符文【堅定】，誓約騎士晉升為 **R【誓約護衛】**。

### 階段二：R ➔ SR【泥濘之判】（公正 / 英勇）
- **情境**：領地周邊抓獲當年襲擊城堡的涉事眼線（如今偽裝成過路行商）。
- **考驗**：面臨私刑復仇還是按封建法律公審的抉擇；同時遭遇敵對小隊突襲，騎士在陣前斬將立功。
- **結果**：確立領地的法度權威，點亮第二道符文【公正】，誓約騎士晉升為 **SR【受封騎士】**。

### 階段三：SR ➔ SSR【荒原之盾】（犧牲 / 憐憫）
- **情境**：大陸地震、各地封印鬆動，成群流民與暴走魔物衝擊領地邊界。
- **考驗**：物資極限緊繃下，如何處置流民；誓約騎士主動帶隊前往最危險的峽谷隘口扼守斷後。
- **結果**：拯救全領地安危，點亮第三道符文【憐憫/犧牲】，誓約騎士晉升為 **SSR【家族誓約長】**。

### 階段四：SSR ➔ UR【榮譽加冕】（正式真名與大圓滿）
- **情境**：領地威名遠播，正式收復故土或粉碎幕後黑手的致命攻勢。
- **考驗**：領主在重整的大廳上，當著所有領民與同伴的面，拔出這把符文俱備的寶劍。
- **結果**：領主親手為他補行正式的授爵禮，傳家寶劍顯現正式真名，誓約騎士正式登上 **UR【永恆守護者】** 巔峰。
